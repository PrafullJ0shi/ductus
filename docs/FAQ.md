# FAQ

**Does it need a GPU?**
No. Everything runs on CPU. A GPU makes generation 10 to 30 times faster.

**Does it need any account or login?**
No. Weights come from public Google Drive and Hugging Face links.

**How long does a page take?**
About 1 to 3 minutes on an 8-core CPU for 150 to 250 words, including the OCR check. Use
`--no-verify` or `--steps 15` for drafts.

**Why does a word sometimes still look wrong?**
The check accepts a word when OCR reads it closely enough after up to 3 rounds. If all rounds
fail, the best attempt is used and counted in `still_failing` in the printed stats. Try a
different `--seed`, `--look neat`, or a cleaner reference line.

**Can it write characters outside ASCII?**
Not yet. The engine's alphabet is 80 ASCII characters; `=`, `<`, `>`, `%` and some others
are drawn as pen marks; the rest are replaced by close ASCII forms.

**Is the output a font?**
No. Every word is generated by the model in context, and every pen mark is drawn with its own
wobble, so a repeated word is never an identical copy. The evaluation measures this.

**Can I get vectors?**
`--svg` writes traced outlines for words and strokes for marks. `--animate` writes an SVG that
writes itself word by word.

**Can I use it commercially?**
The ductus code is MIT. The DiffBrush code is MIT. The DiffBrush weights were trained on IAM,
whose licence is for non-commercial research; check that before commercial use. See
[RESEARCH.md](RESEARCH.md#6-licences-that-matter-for-users).

**Is it meant to fake documents?**
No. It is for notes, mock-ups, design and accessibility. Do not use it to forge signatures or
submit generated work as someone else's.
